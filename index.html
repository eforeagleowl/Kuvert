              Sync between devices

              Keep your devices in step through a secret GitHub Gist. It's unlisted: only someone with its exact link can open it.

              How to make a token

              On GitHub, go to Settings → Developer settings → Personal access tokens → Tokens (classic). Generate a token with only the gist box ticked and use it on each device. It stays in this browser and never goes into backups or the gist.

              How to get a key

              Make a free account on themoviedb.org, then open Settings → API and copy the API Read Access Token. It stays in this browser and never goes into backups.

              Lists & imports

              File format

              A CSV or JSON file with title and year, and optionally shelf (W, N or H), series and part. Letterboxd list exports work too. Each list keeps its own progress.

              Letterboxd ratings and dates

              On Letterboxd, go to Settings → Data → Export your data, then choose the ZIP here (or the ratings.csv and diary.csv inside it).

              About Kuvert

              Kuvert keeps a film list in an envelope and draws one at random, so tonight’s pick is a surprise. The built-in list has every Best Picture winner and nominee, plus honorable mentions.

              Your progress stays in this browser. Kuvert only talks to TMDB when you connect it, and to GitHub when you turn on sync.
