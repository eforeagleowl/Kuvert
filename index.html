              Sync between devices

              Keep your desktop and iPhone in step through a private GitHub Gist that only your account can see.

              On GitHub, go to Settings → Developer settings → Personal access tokens and create a token that can only read and write Gists. Use the same token on each device. It stays in this browser and is never included in backups.
